Wi-Fi Presence Sensor

Turn an ESP32-C5 into a presence sensor for Home Assistant. No router access, no pinging. Everything after this page happens in Home Assistant.

  1. Install the firmware

    Plug the ESP32-C5 into this computer with a USB cable, then:

    This browser cannot flash devices. Use Chrome, Edge or another Chromium-based browser on a computer. Flashing needs a secure (https) page.

    Pick the serial port of the board in the browser's dialog (usually named "USB JTAG/serial debug unit"). Leave "Erase device" off when updating: your key and settings are kept. Tick it for a clean start with a new key.

  2. Copy the pairing key

    When the installation finishes, click Logs & Console. Within ten seconds the sensor prints a box with a 64-character key. Select the key line and copy it.

    It repeats every ten seconds until Home Assistant has paired. You can unplug the board and plug it into any USB power supply afterwards; you will not need this computer again.

  3. Pair it in Home Assistant

    Settings → Devices & services: the sensor shows up under Discovered (found through any Bluetooth adapter or ESPHome Bluetooth proxy). Click Add, paste the key, enter the name of your Wi-Fi. Done: the sensor is now configured from Home Assistant, including later changes.

    The yellow LED on the board tells you where you are: slow blink = running, waiting for Home Assistant; steady = connected; a short flash = activity.

    The integration is not in Home Assistant yet? See the manual, step 2 (one minute, through the Home Assistant Marketplace or by copying a folder).

Board does not start after flashing? If the console shows rst:0x7 (TG0_WDT_HPSYS) over and over, unplug the USB cable, wait a few seconds and plug it in again. See the troubleshooting section.
